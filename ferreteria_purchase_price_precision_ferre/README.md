# Ferretería - Precisión de precios de compra

Conserva hasta ocho decimales en el precio unitario de proveedores, pedidos de
compra y líneas de factura de proveedor. La presentación usa un mínimo de dos
decimales y elimina ceros no significativos hasta un máximo de ocho.

El módulo no cambia la precisión de moneda ni el redondeo de subtotales,
impuestos, totales, saldos o pagos.
