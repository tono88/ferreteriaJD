# Ferretería - Precisión visual de precios POS

Mejora exclusivamente la presentación de las líneas en la pantalla de venta del POS:

- muestra cantidad sin ceros decimales innecesarios y UDM;
- muestra precio unitario con hasta seis decimales;
- muestra el total estándar de la línea con el redondeo monetario de Odoo;
- muestra el descuento cuando corresponde.

No altera precios, impuestos, redondeos monetarios, totales ni datos persistidos.
