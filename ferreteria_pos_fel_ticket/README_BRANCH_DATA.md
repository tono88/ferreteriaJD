# Datos de sucursal para ticket térmico

La versión `18.0.2.0.0` guarda la identidad del ticket en campos configurables de `pos.config`.

La migración incorpora únicamente los datos confirmados para Palinche, Taxisco, El Salto, Gomera y Puerto. No asigna teléfono cuando no fue proporcionado.

JB Central utiliza dinámicamente la información ya configurada en la compañía/diario. La dirección y teléfono definitivos de Prefabricados continúan pendientes de confirmación y no se inventan en la migración.
